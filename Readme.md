## 📖 Overview

**BladeVerse Armory** è un sistema desktop di gestione per un negozio a tema **dark fantasy** — armi leggendarie, lame maledette, reliquie arcane e artefatti da collezione. Sviluppato come progetto scolastico in **C# .NET WinForms**, offre due aree di accesso distinte (Admin e Commesso) con un'interfaccia ispirata all'estetica grimdark: tipografia gotica, icone runiche e texture in pietra scolpita.

## ✨ Funzionalità

### 🛡️ Area Admin

| | Feature |
|---|---|
| 📦 | Gestione inventario (aggiunta, rimozione, aggiornamento articoli) |
| 🤝 | Gestione fornitori (creazione, tracciamento, modifica) |
| 🧾 | Gestione commessi (creazione account, monitoraggio attività) |
| 📊 | Analytics e report (vendite, stock, performance) |
| 📚 | Log di sistema e storico transazioni |

### 🗡️ Area Commesso

| | Feature |
|---|---|
| 💰 | Interfaccia vendita rapida |
| 🔍 | Ricerca articoli e armi |
| 🧑‍💼 | Gestione clienti |
| 📝 | Tracciamento vendite giornaliero |
| 🧾 | Generazione ricevute e fatture |

## 🚀 Come Eseguire

**Requisiti:** Visual Studio 2022, .NET SDK, SQL Server

```bash
# 1. Clona il repository
git clone https://github.com/Na1ky/BladeVerse-Armory.git

# 2. Apri la soluzione in Visual Studio
#    Doppio click su "BladeVerse Armory.sln"

# 3. Configura la stringa di connessione SQL Server
#    nel file di configurazione del progetto

# 4. Esegui le migration / importa lo schema del database

# 5. Premi F5 o clicca "Avvia" per lanciare l'applicazione
```
