# ⚔️ Blade Verse Armory  
### Dark Fantasy Shop Management System

[![License](https://img.shields.io/badge/License-Educational-blue.svg)](#) [![C#](https://img.shields.io/badge/Language-C%23-blue?logo=csharp&logoColor=white)](#) [![SQL Server](https://img.shields.io/badge/Database-SQL%20Server-red?logo=microsoftsqlserver&logoColor=white)](#)

Blade Verse Armory is a **mini project** developed as a school assignment. 
It simulates a dark fantasy–themed shop management system for legendary weapons, cursed blades, arcane relics, and collectible artifacts.
The project provides Admin and Clerk access, allowing basic management of inventory, sales, and shop operations with a gothic-inspired UI.

---

## 🏰 Overview

- **🛡️ Admin Area:** Full control over inventory, suppliers, clerks, and analytics.  
- **🗡️ Clerk Area:** Daily sales operations, customer management, and transaction handling.  

The interface follows a **grimdark fantasy aesthetic** with rune-inspired icons, gothic typography, and carved stone textures.

## 🗂️ Features

### 🛡️ Admin Area
- 📦 Inventory Management (add, remove, update items)  
- 🤝 Supplier Management (create, track, edit suppliers)  
- 🧾 Clerk Management (create accounts, monitor activity)  
- 📊 Analytics & Reports (sales, stock, performance)  
- 📚 System Logs and transaction history  

### 🗡️ Clerk Area
- 💰 Fast sales interface  
- 🔍 Item and weapon search  
- 🧑‍💼 Customer management  
- 📝 Daily sales tracking  
- 🧾 Receipt and invoice generation
